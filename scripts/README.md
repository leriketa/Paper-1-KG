# Scripts
This directory contains the main code notebooks used for the development and analysis of the thesis.

### Description of each notebook
* 
* **` Extractor_corpus_IPCC.ipynb, notebook_01_corpus_clima_con_UNDRR_añadido`**: Notebooks used to collect copora from sources like IPCC and UNDRR.
* **` notebook_01_corpus_clima_taxonomía ampliada.ipynb.ipynb`**: This notebook was used to fusion all the collected climate corpora from different sources, including IPCC and UNDRR explained above since this two sources needed their own script for the extraction of corpora.
